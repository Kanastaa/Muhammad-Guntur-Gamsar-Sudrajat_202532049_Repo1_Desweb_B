Tentang simulasi formulir

Halaman ini adalah tujuan navigasi dari formulir catatan. Jika dibuka lewat tombol submit, isian contoh diteruskan dalam parameter URL menggunakan metode GET.

Website ini tidak memiliki program server atau basis data. Halaman ini tidak menyimpan dan tidak menampilkan kembali isi formulir, serta tidak membuktikan adanya catatan yang tersimpan.

Yang diperiksa dalam demonstrasi

Validasi sebelum berpindah halaman

  • Kolom wajib di isi, tidak boleh dibiarkan kosong.
  • Email contoh menggunakan format email.
  • Jumlah foto berada pada rentang 1 sampai 10.
  • Pernyataan penggunaan data contoh dicentang.

Coba kembali

Kembali ke formulir catatan untuk menguji kolom kosong, format email, atau batas jumlah foto. Buka juga panduan pengamatan untuk memeriksa navigasi antarhalaman.
